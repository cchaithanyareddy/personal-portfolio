# Personal Portfolio Website

A responsive personal portfolio built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run it
1. Extract this ZIP.
2. Open the `Personal_Portfolio_Project` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. An internet connection is needed for Bootstrap, Bootstrap Icons and Google Fonts CDNs.

No npm install or build step is required.

## Customize before submission
- Replace the CR / YOUR PHOTO placeholder with your own profile image.
- Update the email placeholder and add your real GitHub / LinkedIn URLs.
- Review all education, skills, and project details for accuracy.
- Skill progress bars are illustrative; adjust them to your actual skill level.
- The contact form validates in the browser only. A backend or form service is needed to send messages.

## Files
- `index.html` — sections and Bootstrap layout
- `style.css` — responsive theme and styling
- `script.js` — contact form validation and small interactions
